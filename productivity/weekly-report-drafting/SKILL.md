# 周报代填（本人填写层）

> 完整描述："Use when 用户发来周报四栏模板（本周总结/复盘与判断/需要的支持/下周规划）或一句话罗列本周工作要填周报：一句话职责扩写成四段式周报，默认简短版。"

用户的输入通常是一句流水账（"这周负责X根据客户要求对接，还有Y和Z"），任务是扩写成
可直接粘贴进公司系统的四段式周报。

## 输出格式（固定）

- 四个加粗小标题，顺序不变：**本周总结** / **复盘与判断** / **需要的支持** / **下周规划**
- 每节 1–2 句——简短是默认档（用户明确要求过"再简短一点"）；要加长等用户开口
- 正式书面语、无 emoji、无嵌套列表——这是贴进公司系统的周报，不是聊天

## 内容规则

- 只用用户给的事实；不编造量化数字、成果或人名。可以合理泛化动词（推进/跟进/完成/沉淀）
- 复盘节固定两句式：一句"什么做法有效"（提前对齐、及时记录一类）＋一句"需要改进什么"（标准沉淀、流程化一类）
- 支持节固定：希望相关方确认 X / 协助解决 Y
- 下周规划 = 本周工作的自然延伸 + 问题闭环跟进；用户提过的"学习"类条目保留，写成
  "进一步学习X，提升Y能力"，不展开
- 用户没提供原始素材时（只发了模板没发工作内容），先要素材再动笔，不要替用户虚构一周工作

## 用户改稿指令语义

- "再换个说法" = 同长度换措辞，结构不变
- "再简短一点" = 每节砍到 1 句
- "回复一下" = 直接再出一版
