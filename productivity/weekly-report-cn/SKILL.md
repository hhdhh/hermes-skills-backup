# 中文周报（四栏）

> 完整描述：中文周报四栏成稿与迭代（本周总结/复盘与判断/需要的支持/下周规划）. Use when 用户贴「本人填写层」四栏模板、说写周报/汇报本周/回复一下，或要求换说法、再简短.

## 格式（固定）

四个加粗标题各跟一段：**本周总结** / **复盘与判断** / **需要的支持** / **下周规划**。纯文本、无表格、无 emoji、无列表——目标是飞书表单文本框，直接可粘贴。

## 素材处理

用户通常只给一句口语素材（如「负责遥操数据清洗对接 + 装机测试」）。扩写成正式表述，但**只用用户给的事实**——不编条数、百分比、人名等任何量化/归属数据；同类事项合并，动词开头（完成/推进/参与/学习）。

## 每栏写法

- 本周总结：完成了什么 + 产出/结果，1–3 句
- 复盘与判断：一条有效判断（「提前对齐 X 能减少返工」句式）+ 一条待调整（「后续需完善 Y」句式），一正一反
- 需要的支持：对上级/其他部门的具体请求——明确验收标准、协助闭环问题、提前同步计划
- 下周规划：继续/跟进/完善/深入学习，≤3 件

## 迭代指令对照

- 「再换个说法」→ 结构不变，换更书面措辞重发完整四栏
- 「再简短一点」→ 每栏压到 1–2 句重发完整四栏
- 「回复一下」→ 按最新素材直接给成稿
- 用户补充新素材 → 并入对应栏后**重发全稿**，别只发增量

## Pitfalls

- P1 别写素材里没有的成果（如「有效率提升 X%」）——领导会追问出处
- P2 别用列表/表格美化——表单文本框里全乱
- P3 复盘栏别写成流水账，必须一正一反两条判断
