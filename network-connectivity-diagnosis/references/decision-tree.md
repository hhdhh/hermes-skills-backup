# 4 层模型 → 输出 → 结论决策树

> 用决策树形态把"诊断输出 → 结论"沉淀下来。下次主人贴输出，能秒判。

## Layer 1 · 物理链路

### 输出 A：Mac 显示 Wi-Fi 已连 / en0 有 IP
```
结论：客户端物理 OK
下一步：查 Layer 2
```

### 输出 B：Mac 显示 en0 没有 IP / 169.254.x
```
结论：客户端没拿到 DHCP
下一步：重启 Wi-Fi / 换网络
```

### 输出 C：en0 = Wi-Fi 192.168.65.x，但目标 192.168.10.2 走 en5
```
结论：客户端和目标在不同网络
下一步：看 en5 是什么（USB网卡 / Docker bridge / 虚拟机桥接）
```

## Layer 1.5 · ARP

### 输出 A：`arp -n` 显示 `(incomplete)`
```
结论：二层都通不了（隔离 / 设备真不在线）
下一步：确认物理连接 / 路由器后台
```

### 输出 B：ARP 有 MAC，ping 仍 timeout
```
结论：二层 OK，三层/四层被挡
下一步：查 Layer 2-3
```

### 输出 C：清 ARP 后再 ping，MAC 重新出现
```
结论：设备在线
下一步：继续 Layer 2-3
```

### 输出 D：清 ARP 后，ARP 仍 incomplete
```
结论：设备真不在线（或严格隔离）
下一步：物理层 / 路由器后台
```

## Layer 2 · 路由

### 输出 A：`route -n get` 走错 interface（如目标在 192.168.10.0/24 走 en0）
```
结论：路由配置错
下一步：手动加 route 或换网段
```

### 输出 B：目标网关和 Mac 网关不一致但能路由
```
结论：路径长但通
下一步：看 traceroute 哪一跳卡
```

### 输出 C：route 显示 "no route to host"
```
结论：完全没路由
下一步：加 route / 换网络
```

## Layer 3 · 端口服务

### 输出 A：22/80/443 全 timeout，但 ping 同样 timeout
```
结论：防火墙/服务全拦截
下一步：目标设备本地查防火墙
```

### 输出 B：22 timeout 但 80 通
```
结论：SSH 没启 / 防火墙只开 HTTP
下一步：目标设备本地查 SSH 服务
```

### 输出 C：22/80/443 全 timeout 但 ping 通
```
结论：防火墙拦 TCP（不常见，多数防火墙 ICMP/TCP 一起拦）
下一步：目标设备本地查防火墙规则
```

### 输出 D：22 通但 ssh 认证失败
```
结论：跳 Layer 4
下一步：用户/密钥/known_hosts 检查
```

### 输出 E：mDNS / UDP 5000 之类通
```
结论：UDP 通 TCP 死 = 防火墙 TCP-only 拦
下一步：开 TCP 规则
```

## Layer 4 · SSH 协议

### 输出 A：连接建立但 banner 报错
```
结论：协议版本不兼容
下一步：ssh -v 看版本协商
```

### 输出 B：认证失败 / permission denied
```
结论：用户错 / 密钥错
下一步：ssh -v 看具体原因
```

### 输出 C：连接成功但 hang 在 shell 启动
```
结论：服务器侧 shell 启动失败（用户 shell 路径错 / disk full）
下一步：看服务器 /var/log/auth.log
```

## 实战决策流程图

```
[ping 不通]
    │
    ├── arp incomplete ──── 物理/隔离
    │
    ├── arp 有 MAC ──── 二层 OK
    │       │
    │       └── 目标在错网段 ── en5 USB/虚拟网卡 ── 看硬件
    │
    └── nc -G 扫一轮
            │
            ├── 全部 timeout ── 防火墙全拦 ── 目标本地开规则
            ├── 部分通 ── 特定服务活着 ── 换端口试
            └── 22 通 ── 跳 Layer 4 ── 协议/认证
```

## 不要做的事

| 错误诊断 | 真实问题 |
|---|---|
| "ARP 有 MAC = 设备在线" | 二层活 ≠ 三层活 |
| "ping 不通 = 设备离线" | 多数防火墙只挡 ICMP |
| "重启路由器能修" | 客户端 ARP 缓存未清 |
| "改 SSH 端口能解决 timeout" | 端口不通是 Layer 3 不是 4 |
| "肯定是 X" | 没看目标设备本地前不下结论 |
