# Image-to-3D Reconstruction

## 触发条件

当用户说“根据图片生成三维模型”“根据多张 CAD 照片修改模型”“从工程图还原 STL/OBJ”，使用本技能。它是图像理解与无内核 mesh 建模的流程层；基础几何和导出函数可与 `ljg-freecad` 配合。

## 核心原则

- 多图优先：先找不同图片中的共同结构，再建模；不能用单张透视照片的第一印象锁死主体形态。
- 形态优先于细节：先判断是弯头、短筒壳体、法兰、支架、叶轮或外壳，再选择同轴壳体、环筋、径向筋、楔形齿和箱体等 primitive。
- 证据分级：清晰标注是硬尺寸；比例推断是估算；看不清或没有证据的孔、倒角、焊缝、公差不应伪造。
- 产物诚实：照片还原通常是结构沟通级近似 mesh，不得描述成制造级实体、压力容器模型或可直接下料模型。

## 标准流程

1. 清点全部图片，按“同一零件的多个视角 / 不同零件 / 软件界面与背景”分类。
2. 列出共同特征：主轴、开口、内外径、环形台阶、重复阵列、内部筋、中心 boss、检修口、安装脚。
3. 建立参数表，标记 `confirmed`、`estimated`、`unknown`，并在 README 中写清假设。
4. 先实现主体壳体和开口，再实现环筋/底环，最后实现重复内筋、叶片、检修口与支撑。
5. 用 helper + 循环表达重复结构；不要手写几十个重复面，确保后续可以调整数量、角度和半径。
6. 覆盖旧输出前先确认它确实属于本任务；生成脚本、STL、OBJ 和说明文档。
7. 实际执行生成脚本并验证：STL 文件长度应为 `84 + triangle_count * 50`；OBJ 的 `v` 与 `f` 数量应与生成器统计一致；记录包围盒。
8. 如果新增图片推翻主体判断，重构主体并同步更新 README，不要只在旧弯头上继续堆细节。

## 交付格式

- STL：通用查看、切片和网格导入。
- OBJ：Blender/Web 3D 查看。
- 参数化 Python：便于拿到清晰图纸后修正尺寸。
- README：依据、尺寸分级、包围盒、限制和制造风险。

## 常见坑

- 屏幕拍摄有透视、摩尔纹、反光和遮挡；CAD 软件界面不能当作零件几何。
- 视图中被选中的蓝色面通常只是选择高亮，不应自动当成蓝色材料或独立零件。
- 多张图片描述可能包含同一模型的不同方向；先做特征交集，避免将不同视角误判为多个主体。
- 无 OpenCascade 时，STEP 只能是占位或不完整交换格式；优先交付真实 STL/OBJ，并明确限制。

详细的参数化模板与验证要点见 `references/multi-view-mesh-checklist.md`。
