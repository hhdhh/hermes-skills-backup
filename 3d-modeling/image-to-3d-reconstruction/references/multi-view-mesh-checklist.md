# 多视图网格重建检查单

## 本次会话沉淀的可复用判断

新增多张 SolidWorks 屏幕照片后，原先按“90° 大弯头”建模的假设被共同视图推翻。可靠的交集特征是：短粗圆筒壳体、顶部开口、底部厚环、多道外部环筋、中心凸台、交叉底筋、内壁重复径向筋/齿，以及前侧检修口或框架。以后遇到相似任务，应先做这类跨视图特征交集，再决定主体 primitive。

## 参数记录模板

```text
主体形态: <cylindrical housing / elbow / impeller / bracket>
单位: mm
硬尺寸: <直接可读的标注>
估算尺寸: <由比例或已知直径推断>
未知尺寸: <不要伪造>
重复结构: count=<>, angle=<>, radial range=<>
输出限制: mesh-only / no boolean / no manufacturing tolerances
```

## 无依赖几何模式

- 空心壳体：外圆柱 + `inner` 内圆柱面。
- 外部环筋：同轴 annular ring，按高度和半径列表循环。
- 径向齿/叶片：四边形截面的 wedge extrusion，按角度循环。
- 交叉筋：两条正交薄长方体；需要真实旋转时再扩展 mesh 变换。
- 检修口：先用框架和浅层 insert 表达位置；没有剖切/布尔内核时不要声称已经真正切除壳体。

## 交付验证

1. 生成器打印顶点数、三角面数和包围盒。
2. 二进制 STL：读取 header 后的 uint32 三角数，校验文件大小 `84 + n * 50`。
3. OBJ：统计 `v ` 和 `f ` 行，确认均大于零且与生成器统计一致。
4. README 同步更新主体描述、估算参数和包围盒；新增图片推翻旧判断时不能遗留“弯头”描述。
5. 最终说明必须区分“结构沟通级近似模型”和“制造级 CAD 实体”。
