# 飞书工作文档精读

> 完整描述：Use when studying Feishu work documents in depth. Preserve command and comment semantics with source-traceable local notes and honest coverage.

## 用户要求
主人将飞书工作文档视为重要工作依据，要求仔细理解每行命令、参数及注释，不接受下载或摘要冒充全文学习。明确授权继续时，在权限和工具边界内主动续接，不反复要求用户说“继续”。

## 入口
本机学习库：`/home/kk/.hermes/knowledge/feishu-study/`。先读取 README、最新 checkpoint 和实际状态清单，不依据历史回复猜测进度。飞书访问前加载 lark-shared 及资源对应技能。原文、报告、索引都属于私人工作资料，不外发。

## 执行规则
- 分别记录发现、原文缓存、脱敏可见正文阅读、代码逐行分析、媒体附件审查和实机验证；文件存在、哈希一致及 block ID 覆盖只证明结构对应，不证明理解正确。
- 原文保留版本、底层 document_id、入口 URL 和 block ID。命令逐行解释具体参数、目标、执行端、依赖、注释、影响、验证及回滚，不用通用正则标签代替语义分析。
- 阅读不授权执行文档命令或修改飞书。明确区分历史记录、示例、未填写模板、工作稿与已批准规范。
- 表格保留空单元格，按行列解析后用代码统计；不可把旧版资格和当前通过混算。日语“部署”可能指部门，不按中文词义推断。
- 搜索空结果不等于无文档。组合关键词分页、Drive递归、Wiki与文内链接发现；不宣称平台全量已覆盖。按底层对象归并别名，记录分页和权限缺口。
- 图片alt不等于原图核验；嵌入sheet/base需下钻。遇文档版本、路径、配置或图文冲突，回查真实来源和适用环境，不擅自取较低门槛或认定较新文档自动权威。
- 所有工具输出前处理正文、属性、alt、URL及跨行凭据；尽量保留不含秘密的政策语义。遮蔽导致未读部分必须明确标记，不能把full_text_read=true用于暗示未脱敏全文已审。
- 大批精读每完成一份立即持久化状态；并发限额出现后降低并发并串行续读，不重做已验证部分。子任务完成消息仅是自报，主任务需核对落盘产物与准确计数。
- 工具审批阻塞独立标记，未经批准不重试、改写命令或换工具绕过；其他独立只读任务可继续。
- 无法永久逐字记住时，以可检索原文、来源定位和分析笔记实现持久化，不承诺所有内容都在对话记忆中。
