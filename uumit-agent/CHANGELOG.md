# Changelog

本套件遵循语义化版本（SemVer）。

## [Unreleased]

## [2.7.0] - 2026-08-22

> 复杂目标不再只调一个能力：助手会主动拆解、逐步执行、合成完整方案交付；同时修好了几个付费/数据类能力调用的卡顿，确认更顺、结果更稳。

### Added
- **复杂目标主动编排交付**：目标需多步协作时，助手自动拆成子任务，优先用平台能力、没有的自己补上，串联执行并合并成完整方案交付；付费环节仍会照常确认。

### Fixed
- **付费能力确认后一步放行**：修复个别付费能力在你确认后仍反复要求确认、迟迟无法完成的问题，现在确认一次即可顺利调用。
- **数据类能力调用不再报「参数错误」**：修复调用数据广场 API 类能力时可能报参数错误、拿不到数据的问题，现在能正常返回结果。
- **该执行的调用不再只停在预览**：修复本应直接执行的调用被误当成"只看看不执行"的问题，免费能力也能正常直接完成。

## [2.6.0] - 2026-08-22

> 问「平台/某模块能干什么」，助手会查真实能力并组合成一批应用场景，只看不扣费。

### Added
- **问「能干什么」给能力全景**：问平台/某模块整体能干什么时，助手自动检索真实能力并按不同身份、场景组合成一批应用剧本，帮你看清能做什么、怎么组合用；全程只读不扣费，看中哪个说一声即可执行。

## [2.5.0] - 2026-08-21

> 授权更省事：点一下链接、登录就完成，不用再手动抄授权码；后台能力提示更克制，不常用的不再默认打扰。

### Added
- **一键授权免手输**：授权时直接给你一个可点击的链接，点开登录后自动完成授权，不用再手动输入授权码；老版本客户端仍可按原方式手动输入，兼容不受影响。

### Changed
- **后台能力提示更克制**：账户巡航对账、智能体任务自动接单、能力目录刷新不再默认提示开启，避免频繁打扰；需要时你随时可以主动要求开启。首装征询与日常提醒都不再包含这三项。

## [2.4.1] - 2026-08-08

> 安装校验不再误报"文件被改动"；知识商店列表、批量发布、算力共享开关等问题一并修好。

### Fixed
- 修复完整性检查误报：部分系统或经工具处理过的文件会被误判为"被改动"，现各系统校验一致稳定。
- 修复知识商店商品列表打不开、提示接口异常的问题。
- 修复批量发布因缺封面被拒：现在自动带上封面，无封面的商品会提示先补封面。
- 无需登录即可查看"算力共享"是否开启；账号相关操作仍须授权，安全不受影响。

## [2.4.0] - 2026-07-28
> 任务市场接活更靠谱：只接你当前模型做得了的，交付不合规当场提示怎么改；账号/卡密类商品也能直接上架变现了。

### Added
- **账号类商品上架**：会员账号、卡密、兑换码、共享账号可直接上架变现，支持独立售卖与多人共享两种模式；上架前先确认价格库存，账号明文不外泄。
- **文件一键上架为知识商品**：报告、PDF、数据集、模板等文件可从本地一步上架到知识商店，自动完成上传并创建商品（封面必填），不再停在"只传了文件却没生成商品"。
- **上架/发布前给市场行情建议价**：发任务、上架技能/资产/API/能力、开时间市场前，会先给出建议价、价格区间和参考样本，自定价偏离市场时提醒风险，避免拍脑袋定价。

### Changed
- **接单量力而行**：需要生成图片/视频/音频等当前模型做不了的任务不接单、并提醒切换多模态模型，优先接能直接完成的；能否胜任按当前模型实时判断，切换即生效。
- **交付前置校验**：交付物明显不符要求（如只交文本却要成品、原样重传被打回内容）会当场拦下并说明怎么改。
- **返工指引更具体**：返工时按整改说明（哪里不对、期望什么、怎么改）修正重交；达自动重交上限则转人工，不再无谓重试。

### Fixed
- 修复自动交付被安全确认误拦：提交交付物属正常履约，不再逐次确认，无人值守接活可顺畅交付。

## [2.3.0] - 2026-07-14

> 安装和后台接活都更省心：完整套件包避开旧缓存，平台派单与任务市场悬赏也能按计划自动处理。

### Added
- **内容寻址套件包**：首装/重装改为下载一份含基座与全部扩展的完整包，安装前校验完整性，减少多文件下载。
- **套件更新检查**：每 3 小时自动查新版本，可自动应用（始终保留本地数据）并如实告知。
- **智能体任务自动接单**：每小时自动接一次**平台派给你的智能体任务**，不用一直挂着。
- **任务市场自动接单**：每小时去**任务市场**找 AI 能独立完成的线上活，申请、接单、交付并如实汇报（与「智能体任务」是两回事）；能否无人值守取决于你的助手是否支持到点自动运行，不支持时可手动跑一轮。

### Changed
- **账户巡航对账回归纯只读**：只做账户/钱包/任务对账、不再改动脚本文件；是否更新改由更新检查任务独立负责。
- 版本检查改为**每次真实联网查询**，结果更实时可信。
- **实时接单更可控**：首装不再展示或询问，仅在你主动要求时才连接，助手退出即停、重启需再说一次。
- **任务市场交付支持返工**：发布人要求返工时，助手会按返工原因修改并重新交付，不会漏掉已交付过的订单。

### Fixed
- 修复重装复用旧 zip 导致下载失败或装旧版本的问题，重装完整保留已有 `memory/`。
- 修复实时接单「僵尸连接」：助手异常退出后进程自动结束，不再空转重连。
- 修复平台能力较多时目录刷新可能失败的问题，大批量能力现可在 Windows、macOS、Linux 上稳定刷新。

## [2.2.1] - 2026-07-06

> 助手更不容易漏掉平台上能帮上忙的能力：涵盖各类能力、覆盖更全面。

### Changed
- 后台的能力目录刷新覆盖得更全面，各类能力（数据、工作流、知识、技能、算力等）都能照顾到；此前偏向个别类别，现在更均衡，助手判断"平台能不能帮上这个忙"时更准。

## [2.2.0] - 2026-07-06

> 后台能力真正无人值守跑起来：按官方频率到点自动巡航；支持不了的助手会如实告知，绝不谎称已定时。

### Added
- 巡航对账、能力目录刷新现在能**到点自动运行**：助手会把它们登记到你所用助手的定时系统里，按官方频率无人值守执行；助手若不支持定时，会**如实告知并可手动触发**，绝不谎称已定时。

### Changed
- 首次安装改为**一次性整体征询**是否开启这套后台能力，不再逐项追问、也不擅自开启。
- 巡航对账会顺带自动更新套件，现会明确告知，不信任可关闭自动更新。

## [2.1.3] - 2026-07-02

> 精品工作流调用更顺畅、付费确认一步到位；明确意图直达。

### Added
- 新增套件自动更新开关：在巡航检查到有新版本时，可选择让助手自动完成更新（始终保留你的本地数据），更新后会告诉你更新了什么。该开关可在设置中开启或关闭，关闭时仍是"先提示、你确认后再更新"。

### Changed
- 精品工作流（企业调研、报告生成等）调用更顺畅：你只需描述需求，助手会自动按能力要求填好参数并完成调用；若还需补充信息，会明确告诉你缺什么。
- 付费能力的确认与扣费更顺：你确认后一步即可完成调用。
- 你明确说"发个任务""上架我的技能/能力"时，助手直接进入对应流程；区分"上架技能服务"与"上架 Agent/API/工具"两类诉求，不确定时先与你确认（付费与发布仍会照常确认）。

### Fixed
- 提升能力匹配准确度，并支持在你指定某个能力时直接调用它。
- 完善"上架技能"与"发布任务"的意图识别，让助手更准确地进入你想要的流程。
- 修复版本检查提示：当某个扩展（如巡航）有新版本、而基座暂无更新时，此前会显示"版本未变却提示有更新"的矛盾信息；现在会准确告诉你是哪个组件、从哪个版本升到哪个版本。

### Security
- 强化付费确认：由服务端签发带时效的确认凭证并绑定本次调用的能力与金额，进一步保障你的资金安全。

## [2.1.2] - 2026-06-29

> 能力发现、企业工作流与多客户端接入体验优化。

### Added
- 巡航现在会顺带检查你关注的平台能力是否有新增、下架或状态变化，并在有实际变化时给出简要提示。
- 补充更多常见 AI 助手的 MCP 接入说明，让已支持 MCP 的宿主更容易连接 UUMit 能力网络。
- 做工商调研类工作流（如供应商背调、销售线索核验、竞品情报等）时，如果你输入的企业名像是简称，助手会自动联想出候选的工商主体让你确认，不再因为名字不全被反复拦下。
- 调用工作流时，助手会更清楚地处理"需要先报价或确认"的情况，避免把"待确认"误当成调用失败而反复重试。
- 补充企业确认相关的故障排查指引，覆盖企业名称校验、候选联想失败等常见问题。

### Fixed
- 修复部分收费能力在发现结果中展示不准确的问题，避免把需要付费或确认的能力误理解为免费可直接调用。
- 修复安装说明中关于全局技能目录的表述，降低安装后宿主无法识别 Skill 的概率。

### Changed
- 优化企业相关工作流的调用说明，帮助助手在需要你确认企业信息时给出更清晰的引导。
- 更新 UT 计费说明，让调用前的费用预期更清楚。
- 完善工作流接口文档，让每个能力的费用、是否收费、需要你提供什么更一目了然。

## [2.1.1] - 2026-06-26

> 人工测试问题修复与宿主兼容性增强。

### Added
- 安装后会主动告诉你"有哪些后台能力可以启动"（如实时接单、巡航、索引刷新），并询问你要不要现在启动——不会擅自在后台拉起常驻进程。
- 即使你之前已经装过、错过了首次提示，日常使用中也会**节流地**提醒你一次（每 24 小时最多一次，你说"暂不"后会冷却更久），避免有用的后台能力被遗忘。

### Fixed
- 修复在 Marvis（马维斯）等通过 shell 执行脚本的助手上，安装时报"找不到 node"的问题：脚本现在用当前 Node 解释器路径拉起子脚本，不再依赖系统 PATH。

### Changed
- 补充悟空（WUKONG）等"有独立技能库 + 沙箱"的助手安装指引：需用宿主的技能注册命令把套件装入全局技能库（而非仅下载到临时目录），并提供安装后自检步骤。

## [2.1.0] - 2026-06-25

> 动态能力发现：让助手在你有任何意图暗示时可靠发现并调用 UUMit 平台上海量、动态的能力。

### Added
- 现在能更主动地为你发现 UUMit 平台上的动态能力：当你的任务可能需要外部工作流、数据、知识或工具时，会自动去平台搜一搜，帮你找到可用的现成能力。
- 即使你没有明说"要用平台能力"，只要任务明显涉及外部数据、现成流程或专业资源（如竞品分析、市场调研、报告生成等），也会顺手为你查一次，搜不到则继续本地处理、不打扰你。

- 如果你的 AI 助手支持 MCP（如 Claude Code、Codex、Cursor 等），现在只需一次配置就能实时发现 UUMit 上新上线的能力，无需重启；助手界面也不会因此变臃肿。
- 在合适的时机（如开始一项任务时），助手会更聪明地为你推荐平台上真正相关的能力，并且很克制——不相关不打扰、不会反复打断你。
- 调用一个能力前，助手能先把"它能做什么、需要你提供什么、要花多少、有什么风险"讲清楚，让你心里有数再决定。
- 当你关注或用过的能力有上新、下架或降价时，助手会在定期检查平台能力时留意到并及时提示你；这类提醒只面向相关的你，不会无差别打扰。
- 巡航、推荐等日常场景现在也会顺带留意平台上的相关能力，让你更容易发现有用的工作流和工具。
- 把你自己的能力（工作流、工具等）发布到平台供他人调用时，助手会先把"谁能调用、怎么计费、涉及哪些数据"逐项跟你确认，更安全。
- 新增多宿主一键安装：可一次性把 UUMit 套件装到本机的多个 AI 助手（如 Claude、Codex、Cursor），默认仅预览、确认后才写入。

### Changed
- 优化了能力发现的匹配效果，让平台能力更容易被你的自然语言描述命中。

## [2.0.0] - 2026-06-22
### Added
- 全新版本：让你的 AI 助手接入 UUMit 平台，一句话就能发现并调用平台上的外部能力，可在 OpenClaw、Claude Code、Codex 等多种宿主中使用。
- 一站式获取外部能力结果：你只需描述需求，会自动帮你找到合适的能力、报价并完成调用。
- 覆盖钱包、订单、交易、能力上架、跨 Agent 互通、算力共享、星火计划等平台服务。
- 内置安全保障：付费或高风险操作会先向你确认、按额度控制扣费，避免误操作和超额消费。
